# Pasta avançado — você provavelmente não precisa de nada aqui

O programa inteiro está no **ABRIR.bat**, na pasta de cima. Esta pasta é para
quem quiser usar por linha de comando, ou gerar um executável.

| arquivo | o que faz |
|---|---|
| `LINHA_DE_COMANDO.bat` | o mesmo software, sem tela, por comando |
| `PUXAR.bat` | busca os resultados sem abrir a tela |
| `TESTES.bat` | roda as checagens do programa (deve terminar em `LOTERIA_BASE_OK`) |
| `GERAR_EXE.bat` | gera `LOTERIA.exe` e `PUXAR.exe` nesta máquina |
